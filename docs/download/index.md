### Antivirus &amp; Firewall (read this first)

This is the **#1 reason** a private-server client won't run. Custom RO clients are *not* code-signed like big commercial games, so Windows Defender, third-party antivirus, and the firewall often flag them as a **false positive** and silently quarantine or block files. It's the nature of private servers &mdash; the client is safe, it just isn't signed.

If the game won't launch, crashes instantly, or files keep disappearing after extraction:

<div class="sov-troubleshoot-list" markdown>

- **Add an exclusion** for the whole SovereignRO folder in Windows Defender / your antivirus (best option &mdash; keeps you protected elsewhere).
- Or **temporarily disable** real-time antivirus protection and the Windows Firewall while you patch and launch.
- **Re-extract the client** after adding the exclusion &mdash; deleted/quarantined files won't come back on their own.
- **Run as Administrator** (right-click the game/patcher &rarr; Run as administrator).
- Allow the game through the firewall if Windows prompts you on first launch.
